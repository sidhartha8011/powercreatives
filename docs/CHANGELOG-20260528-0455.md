## View/Edit Text Parity CSS Fix

**Status:** UNVERIFIED (awaiting user browser verification)

### Ändring
Fixat CSS-diskrepanser som orsakade att copy-kort-texten ändrade utseende vid dubbelklick-editering (view mode → edit mode).

### Root Cause
Tre CSS-egenskaper skilde sig mellan view mode (`.pcm-copy-text`) och edit mode (`.ProseMirror p`):

1. **font-family** — View mode ärvde `Inter` via `.pcm-client-review`. Edit mode hade explicit `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif` med Inter saknat. Olika fonter → olika glyph-metriker → text "hoppar".
2. **white-space** — View mode hade `pre-wrap`, edit mode hade default `normal`.
3. **word-break** — View mode hade `break-word`, edit mode hade default `normal`.
4. **Wrapper font-size** — `.pcm-inline-editor` satte `12.5px` som skapade en konkurrerande bas.

### Fix (1 fil, +13/-6 rader)
- `client-review.css` rad 587: `font-family: -apple-system, ...` → `font-family: inherit`
- `client-review.css` rad 587: Added `white-space: pre-wrap; word-break: break-word;`
- `client-review.css` rad 1204: `font-size: 12.5px` → `font-size: inherit`, `line-height: 1.5` → `inherit`, `color: var(--ink)` → `inherit`
