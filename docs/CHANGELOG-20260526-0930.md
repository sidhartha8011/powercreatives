# CHANGELOG 2026-05-26 09:30 — Client Review Board: Icon-Only Copy Button

Converted the Copy button on copy variations to be icon-only to solve text wrapping issues in the action row.

Plugin: v1.4.3 → v1.4.4

## Root cause
The text "Copy Text" inside the copy button caused the button to wrap or break layout aesthetics when rendered next to long text and other action buttons.

## Fix
- Removed the text label "Copy Text" in `CreativeAssetCard.tsx`.
- Retained the double-document Lucide `Copy` icon.
- Added `title="Copy Text"` and `aria-label="Copy Text"` for screen readers and tooltips.
- Scoped CSS rule in `client-review.css` targeting `#pcm-root .pcm-btn-copy` to format it as a circular `30px` icon button (`border-radius: 50%`, `padding: 0`, and `display: inline-flex`) matching the vertical footprint of the adjacent buttons.

## Files changed
1. `app/src/modules/Approvals/components/CreativeAssetCard.tsx` — JSX modified to remove text label, add title and aria-label.
2. `app/src/modules/Approvals/client-review.css` — CSS modified to style the button as a circular icon button.
3. `power-creatives.php` — Version bumped from 1.4.3 to 1.4.4.

## Verification
- `npm run build`: Success in 22.95s.
