# Changelog — 2026-07-07 06:45 — Root fix: Tailwind utilities vs wp-admin CSS layers

## Summary
All Tailwind utilities are now emitted with !important (`@import "tailwindcss" important`).
Root cause, proven: v4 wraps utilities in @layer; WordPress admin's unlayered
`input { font-size: 14px }` (wp-admin/css/forms.css:13) beats any layered utility on the
same property, which broke the card title (32px→14px) and pinned card inputs at 14px.

## Changes
- `src/index.css`: `@import "tailwindcss" important;` + rationale comment (documented
  trade-off: !important utilities also beat runtime inline styles — keep utility classes
  off properties JS libs set inline, e.g. dnd transforms).
- `ui/input.tsx` / `ui/textarea.tsx`: `text-base md:text-sm` → `text-sm` (responsive class
  is emitted after base utilities, so it would still beat consumer overrides even with the
  important flag). Desktop pixel-identical; mobile 16→14px.
- Prior wrong-theory commit a3c4db6 was reverted (reset to ee6a7e2) before this fix.
