# CHANGELOG — 2026-05-29 08:48

## Approvals: ClientReviewPage post-submit lockdown

**Status:** UNVERIFIED (awaiting user browser verification)

### Summary

Fixed a latent active bug in the client review surface where the read-only gate `set?.status === 'completed'` was dead code (the `'completed'` enum was migrated out in v1.8.0 → 'approved' → 'launch'). Six interactivity guards relied on `isSubmitted` (local React state) alone, so refreshing the page after submission reset the lock and allowed re-submission, which re-fires the outbound webhook (`PCM_Approvals_Service::submit_review` is not idempotent server-side).

Introduces a typed `isPostSubmitStatus()` helper + `POST_SUBMIT_STATUSES` constant in `Approvals/types.ts`, and a `const isLocked = isSubmitted || isReadOnly` combined-truth derived state in `ClientReviewPage.tsx`. All six interactivity guards, the post-submit "thanks" view, and child component locking now consult `isLocked` so server-persisted truth survives page refresh.

### Key Changes

1. **`app/src/modules/Approvals/types.ts`**
   - Added `POST_SUBMIT_STATUSES: ReadonlyArray<ApprovalStatus> = ['launch', 'live', 'archived']` (semantic set, not positional).
   - Added typed helper `isPostSubmitStatus(status)` for use across the module.

2. **`app/src/modules/Approvals/components/ClientReviewPage.tsx`**
   - Replaced dead `set?.status === 'completed'` literal with `isPostSubmitStatus(set?.status)`.
   - Introduced `isLocked` derived state combining local `isSubmitted` and server-side `isReadOnly`.
   - Migrated all six interactivity guards (autosave-local, autosave-server, `handleToggleApprove`, `handleThreadChange`, `handleApproveAll`, `handleSubmitReview`, `handleConfirmSubmit`) from `isSubmitted` to `isLocked`.
   - Added explicit `if (isLocked) return;` guards at top of both submit handlers (`handleSubmitReview`, `handleConfirmSubmit`) — eliminates the webhook re-fire vector on the client side regardless of UI-button visibility.
   - Updated the post-submit thanks-view trigger (`if (isLocked && !isTeamMember)`) so it persists across page refresh.
   - Updated `<CreativeAssetCard isSubmitted=...>` prop to use `isLocked || submitMutation.isPending`.
