# CHANGELOG - 2026-05-23

## [1.2.1] - 2026-05-23

### Fixed
- Fixed bug in the Ads module where the user's sidebar settings (Audiences and Variations count) were not respected by the backend generator due to LLM non-determinism, by strictly array-slicing and grouping the returned audiences and angles to the exact user-requested count parameters in `PCM_Copy_Service`.
- Fixed client approval sharing flow in the Ads module: corrected the public shareable link URL to point to the dynamically discovered [power_creatives] shortcode page with query parameters instead of a non-existent /public/approval/ route (resolving the WordPress 404 error), and implemented a robust execCommand fallback to ensure link copying is 100% reliable within WordPress admin iframes and non-secure HTTP environments.
- Fixed bug in the Ads module where the brand logo and reference images were not sent to the image generator: imported and called syncBrandAssetsToSession inside the ContextPanel's onChange handler in AdsSidebar.tsx to keep the active session reference images synchronized when the brand changes.
