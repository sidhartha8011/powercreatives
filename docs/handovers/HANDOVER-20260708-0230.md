## 5. Traps that BIT US — do not relearn these

1. **The trpc client is a hand-rolled proxy — hooks only.** There is NO
   `utils.client.x.y.query()`. Imperative fetch = exported `apiFetch('endpoint')`.
   Copy's `handleBrandSaved` still contains the broken call behind a silent
   catch — **flagged to PO, fix NOT approved yet**. (Memory + SESSION_LOG.)
2. **Arbitrary font-size utilities inherit line-height.** `text-[11px]` inside a
   `text-sm` container renders taller than in a `text-xs` cell. Shared recipes
   must PIN `leading` (CELL_PILL carries `leading-4` for exactly this).
3. **Tailwind `important` flag layer war** (see previous handover §5) — plus:
   descendant selectors in shared grids (`[&_td]`) beat nested tables' own
   classes; the DataTable grid is direct-child-scoped for this reason.
4. **`group-hover` is a no-op on coarse-pointer devices** — accepted for header
   icons/row actions by explicit PO decision; don't extend it to critical-path
   affordances without asking.
5. **wpdb returns strings** — `Number()` at every boundary.
6. Two sort systems fight: table view hides the board's sort dropdown; headers
   own sorting there. Sub-row cell layouts are POSITIONAL — adding a table
   column means adjusting sub-row cell counts/colSpans in DeliveriesTable.
