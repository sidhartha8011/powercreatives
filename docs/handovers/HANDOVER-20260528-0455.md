# HANDOVER — 2026-05-28

## Session summary
Fixat den olösta view/edit text parity-buggen från sessionen 2026-05-27.

## Vad var problemet
Copy-kort-texten på klientgranskningssidan ändrade utseende vid dubbelklick-editering. Föregående utvecklare gjorde 4 misslyckade fix-försök (tog bort inline style, tog bort mt-2, lade till inherit på inputs, tog bort dubblett footer).

## Root cause (verifierat mot dist/index.css)
Tre CSS-diskrepanser mellan view mode (`.pcm-copy-text`) och edit mode (`.ProseMirror p`):

1. **font-family** — `.ProseMirror p` hade explicit `-apple-system, ...` som SAKNADE `Inter`. View mode ärvde `Inter` från `.pcm-client-review`. Olika fonter = olika glyph-metriker = text "hoppar".
2. **white-space** — View mode: `pre-wrap`. Edit mode: default `normal` (saknades).
3. **word-break** — View mode: `break-word`. Edit mode: default `normal` (saknades).

Sekundärt: `.pcm-inline-editor` wrapper hade `font-size: 12.5px` och `line-height: 1.5` som skapade en konkurrerande bas.

## Vad jag ändrade
**1 fil:** `app/src/modules/Approvals/client-review.css`

- Rad 588: `font-family: -apple-system, ...` → `font-family: inherit`
- Rad 590-591 (nya): `white-space: pre-wrap; word-break: break-word;`
- Rad 1206: `font-size: 12.5px` → `font-size: inherit`
- Rad 1207: `line-height: 1.5` → `line-height: inherit`
- Rad 1208: `color: var(--ink)` → `color: inherit`
