## 4. ARKITEKTURKRITISKA BESLUT

- **Document-scoped state via namespaced keys** — Valde `${docId}::${mediaId}` som nyckelformat istället för `useRef` + reset pattern. Anledning: ingen race condition, behåller state vid dokumentbyte, ingen manuell cleanup. Avvisade alternativ: (a) lagra i Jotai store (ger persistence men kräver schema-ändring), (b) reset `useEffect` (fragilt, race conditions).
- **Sekventiell vs parallell bildgenerering** — Valde sekventiell (`for...of` + `await`). Parallell orsakade stale ProseMirror-positioner. Konsekvens: 2 bilder tar ~2 min istället för ~1 min. Acceptabelt trade-off för korrekthet.
- **Image.extend() vs Image.configure()** — Tiptap kräver `addAttributes()` för att preservera custom DOM-attribut genom HTML→ProseMirror round-trip. `HTMLAttributes` sätter bara defaults men registrerar inte schemat.
- **Tiptap Comments: bygga eget** — Officiella Comments-extensionen kostar $49+/mån (Tiptap Cloud). Beslut: bygga lightweight custom lösning med `CommentMark` + JSON-lagring i egen databas. Ej prioriterat nu.
