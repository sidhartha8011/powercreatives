### 🔴 T2I Model Auto-Deselect Race Condition
**Symptom:** GPT Image 2 T2I blir vald även när `useLogo=true` är på — fyrar trots att UI visar den som disabled.

**Root cause:** [useImageGeneration.ts:187-195](../../../app/src/modules/Image/hooks/useImageGeneration.ts#L187-L195) deselect-effekten saknar `selectedModels` i deps-arrayen.

**Sekvens:** Effekt-1 (default-population från `settings.defaultImageModels`) sätter selectedModels EFTER att Effekt-2 (deselect) kört med tom closure → t2i förblir vald.

**Fix:** Lägg `selectedModels` i deps. ~1 rad.
