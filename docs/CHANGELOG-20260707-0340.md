# Changelog — 2026-07-07 03:40 — Site ↔ Project connection

## Summary
Plain connect/disconnect link between Sites and Projects, controllable from three UI
surfaces. No publishing semantics. One source of truth: `projects.siteId`.

## Database (DB 1.33.0 → 1.34.0)
- `wp_pcm_projects`: + `siteId int(11) DEFAULT NULL` + `KEY idx_siteId` (additive dbDelta;
  no backfill). `siteId` references the `{prefix}sites` WP-connection table — NOT the SEO
  Hub tenant site (`deliveries.seoSiteId`). NULL = not connected. N:1 by design: many
  projects may connect to the same site. Dangling FK policy mirrors `deliveryId`: deleting
  a site leaves pointing projects untouched; resolvers return null; UI shows "Not connected".

## Backend
- `includes/core/class-pcm-hierarchy.php`: + `site_for_project(?int): ?int` and
  `projects_for_site(int): array` (reverse lookup — always a list of full chains). All
  cross-module reads of the link go through these; only the assets module (owner of the
  projects table) touches `projects.siteId` directly.
- `includes/modules/assets/controller.php`: + `PATCH /assets/projects/{id}/site`
  (`set_project_site`, body `{siteId: int|null}`, null disconnects). Ownership: project via
  PCM_Access scope (owned or granted), site via `PCM_DB::get_site()` → 404 otherwise.
  `get_projects` now returns `siteId`.
- Sites module backend: zero changes (stays a pure credential manager).

## Frontend (all three surfaces call the same `assets.setProjectSite` mutation)
- `lib/trpc-routes.ts`: + `assets.setProjectSite`.
- Sites table (`modules/Sites/index.tsx`): + "Project(s)" column — dropdown checkbox list;
  checked = connected to this site; toggling one project never affects others; shows
  "other site" hint when a project is connected elsewhere; "Not connected"/"—" states.
- Projects (`modules/Projects/index.tsx` + `types.ts`): + "Site" select next to the
  Delivery select in the project detail header; `siteId` added to the Project type.
- Deliveries (`modules/Deliveries/DeliveryDialog.tsx`, edit mode): + "Connected projects —
  site per project" section listing every project with `deliveryId` = this delivery, each
  with an instant-apply Site select (the link lives on the project, not the delivery).
