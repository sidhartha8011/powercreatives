## Multi-Article Approvals Packaging & Type-Safety Polish in Content Writer

**Status:** UNVERIFIED (awaiting user browser verification)

### Summary of Changes
Implemented a robust multi-article selection queue inside the Content Writer, enabling users to batch-select one or many documents and send them to the shared Client Approval Board with complete type-safety and React performance optimization.

### Key Enhancements

1. **State Management & Selection Leak Prevention (`store.ts`)**
   - Added `selectedDocumentIdsAtom` base atom using type-safe value-casting (`atom([] as string[])`) to ensure automatic inference as writable `PrimitiveAtom`.
   - Polished writable derived `removeDocumentAtom` to prune deleted document IDs in-place, eliminating state leaks and "ghost" selected item counts.
   - Simplified base atoms (`activeDocumentIdAtom`, `activeProjectIdAtom`, etc.) with `null as string | null` type assertions to bypass strict generic inference bottlenecks.

2. **Document Queue Checklist & Bulk Actions (`DocumentQueuePanel.tsx`)**
   - Placed styled shadcn `<Checkbox />` elements on the left of all document cards in the queue, allowing independent checkboxes separate from editor navigation.
   - Introduced minimalist **"Select all"** and **"Clear"** utility triggers in the queue panel header using design token variables.

3. **Dynamic Packaging & Performance Optimization (`index.tsx`)**
   - Wrapped calculations for `targetDocs`, `hasEmptyDoc`, and `canSendApprovals` inside React `useMemo` hooks, completely avoiding expensive array scanning on editor inputs and typing.
   - Configured `handleCreateApprovalSet` to package dynamically checked articles under `snapshot.articles` JSON array, gracefully falling back to the active editor document if zero items are checked.
   - Updated the header primary button to change text dynamically (e.g. `"Send 3 Articles to Approvals"`) and toggle disabled state seamlessly.
