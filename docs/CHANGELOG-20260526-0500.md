# CHANGELOG — 2026-05-26 05:00

- **Apple Premium Comments & Real-Time Backend Persistence** — Redesigned the comments display block on creative cards to use a beautiful, semi-transparent white glassmorphic box with message bubble icons and circular gray stängningsknappar, completely replacing the heavy orange-bordered container. - **Multi-Comment Threaded System Upgrade** — Replaced the single-string-per-asset comment model (`Record<string, string>`) with a full threaded comment system (`Record<string, CommentEntry[]>`). Each comment now has its own id, author, text, createdAt timestamp, status (New/Team reply/Done), and parentId for threading. Backend sanitization in both `save_review_draft()` and `submit_review()` updated with legacy string→array migration. Frontend state, localStorage draft, hydration, autosave, and submit payloads all upgraded. Inspector panel now renders a scrollable chronological thread with inline reply threading, per-comment status dropdowns, and real relative timestamps. CreativeAssetCard shows a clickable comment-count badge instead of a single text. (2026-05-26)
