# Changelog - 2026-05-16 08:25

## Fixed
- `includes/modules/image/service.php` — `final_prompt` template (rad 736-747) added missing placeholders `{{phone}}`, `{{url}}`, `{{seasonEvent}}`, `{{campaignTheme}}`. Vars were built in `build_image_context()` but never consumed by the template — brand phone, website, season and campaign theme silently never reached the image model.
- `includes/modules/image/service.php` — `build_image_context()` (rad 771-777) now strips `http(s)://` protocol and trailing slash from URL before injection. Cleaner prompt text, fewer tokens, prevents AI from rendering raw URL syntax in generated images.

## Changed
- `includes/modules/image/service.php` — URL sanitization switched from `esc_url_raw()` (intended for DB/attributes) to `sanitize_text_field()` (correct for plain prompt text).

## Notes
- Placeholder ordering in `final_prompt` template now matches `context_suggestions` for consistency across the 4 image-prompt templates.
- Side effect (positive): `concept_suggestions_user` and `brief_optimization_user` templates also benefit from the URL cleanup since all 3 share `build_image_context()`.
- `[PCM-SOND]` diagnostic logs remain in place to verify the fix — to be removed after VERIFIED.
