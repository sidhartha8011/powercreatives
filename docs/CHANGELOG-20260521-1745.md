# CHANGELOG - 2026-05-21

## [1.2.0] - 2026-05-21

### Added
- Generalized the backend REST endpoint `POST /assets/save-to-project` in `controller.php` to accept bulk `assetIds` alongside the legacy `assetId` parameter.
- Integrated high-fidelity hover checkboxes and selection border states on media cards in `Projects/index.tsx`.
- Refactored `MoveToProjectDialog` to be polymorphic, dynamically supporting bulk reassignments for either `media` (calling `trpc.assets.saveToProject`) or `copy` (calling `trpc.copy.saveToProject`) based on the active tab context.
- Configured selection cleaners to reset selection arrays on tab changes.
