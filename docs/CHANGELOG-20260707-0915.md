# Changelog — 2026-07-07 09:15 — Global DataTable: accordion rows

## Summary
`@/components/ui/data-table.tsx` (the app's designated global table) now supports
expandable rows: pass `renderExpanded(row)` (and optionally `rowCanExpand(row)`) and
each row gets a chevron that opens a full-width sub-row. Purely additive — Sites and
every other consumer are unchanged without the prop.

## Changes
- `renderExpanded` / `rowCanExpand` props; internal `expandedKeys` Set keyed by
  `rowKey`. Chevron column (36px) prepended when enabled; the chevron
  stopPropagation()s so `onRowClick` (edit/navigate) still owns the row itself.
- Sub-row = `<tr data-subrow><td colSpan>` — rendered content is EXEMPT from the grid
  cell styling.
- GRID_CLASS selectors rescoped from descendant to direct-child
  (`[&_td]:` → `[&>tbody>tr:not([data-subrow])>td]:`, same for th). Reason: with the
  Tailwind v4 `important` flag every utility is `!important`, so the old descendant
  selectors (specificity 0,1,1) would silently beat the cell classes (0,1,0) of any
  table NESTED inside an expanded row — exactly the style-bleed class of bug from the
  typography war. Direct-child scoping means nested tables aren't matched at all.
  Existing consumers match the same elements with the same winners → pixel-identical.
- Empty-state `colSpan` accounts for the chevron column.
