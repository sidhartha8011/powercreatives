# CHANGELOG 2026-05-26 10:05 — Client Review Board: Clipboard Screenshot Pasting

Implemented a secure, highly-polished, senior-developer solution allowing public review clients and team members to paste screenshots and images (`Ctrl+V` / `Cmd+V`) directly from their clipboard into the comments inspector.

Plugin: v1.4.6 → v1.4.7

## Key Features & Architectural Enhancements

1. **Global Reusable Upload Hook (`useImageUpload`):**
   - Created a generic hook `app/src/hooks/useImageUpload.ts` utilizing HTML5 `<canvas>` to compress images on the client side (max 800px, quality 0.75) to prevent database or network bloat.
   - Reuses the existing `trpc.writer.uploadImage` mutation, avoiding redundant backend endpoints or security vulnerabilities.

2. **Clipboard Paste & Preview UI:**
   - Captured clipboard paste events (`onPaste`) inside `ClientCommentInspector.tsx`.
   - Rendered responsive, circular draft thumbnail previews under the input row with remove capabilities.
   - Integrated a loading indicator (`Loader2` spinner) while the pasted screenshot is uploading.
   - Disabled the Send button during uploads to ensure transaction integrity.

3. **Comment Attachments Gallery & Lightbox:**
   - Extended the `CommentEntry` interface in `types.ts` with `attachments?: string[]`.
   - Rendered sent attachments as clean klickable thumbnails under the comment text.
   - Wired up a portal-based lightbox overlay to view full-size screenshots.

## Files changed
