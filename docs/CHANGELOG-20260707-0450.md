# Changelog — 2026-07-07 04:50 — Delivery card redesign + work log + seoSiteId retirement

## Summary
Opening/editing a delivery is now one clean Notion-style card: inline-editable title, a
single properties table with auto-saving cells, a projects table with per-project site
connections, and a new append-only work log.

## Database (DB 1.34.0 → 1.35.0)
- NEW `wp_pcm_delivery_logs` (`id, deliveryId, userId, note, createdAt` + idx) — owned by
  the Deliveries module. Append-only "what was done" notes.
- `deliveries.seoSiteId` marked DEPRECATED in the schema comment (column kept; additive-only
  migrations). It was write-only — verified zero readers anywhere in the codebase.

## Backend (Deliveries module only)
- `controller.php`: + `GET /deliveries/{id}/logs` (newest first, userName joined from
  pcm_users) and `POST /deliveries/{id}/logs` (`{note}`, sanitized, non-empty). Both scoped
  through `PCM_DB::get_delivery_by_id`. `seoSiteId` no longer accepted on create/update
  (documented as deprecated in the sanitizer).
- `service.php`: `format_delivery` no longer returns `seoSiteId`.

## Frontend
- `lib/trpc-routes.ts`: + `deliveries.logs`, `deliveries.addLog`.
- `DeliveryDialog.tsx` rebuilt:
  - Title = delivery name, edited in place (blur-save; empty restores).
  - Properties table (Status | Client | Type | Module access | Brand | External ID): each
    cell is its control; edit mode auto-saves per field; create mode submits classically.
  - Type select applies the central module preset; Module access cell opens a checkbox
    popover for custom overrides (replaces the standalone checkbox grid).
  - Projects section: the delivery's projects (deliveryId match), per-row Site
    connect/disconnect (`assets.setProjectSite`) + media count; "+ Add project" / ✕ via
    `assets.setProjectDelivery`. Subcomponent — queries run only while the card is open.
  - Log section: input + Add (Enter works), entries newest first with author + timestamp.
  - REMOVED from the card: "SEO module — site" select and the single "Project" access-grant
    select (stored `deliveries.projectId` values untouched — access grants keep working).
- `types.ts` / `useDeliveries.ts`: `seoSiteId` removed from types and inputs.
