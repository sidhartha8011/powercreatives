# CHANGELOG 2026-05-26 07:00 — Kanban Visual Refactor: Round 2 Fixes

Follow-up fixes on the visual refactor (CHANGELOG-20260526-0600.md) based
on user feedback after smoke-testing. Still pure visual / no logic.

Plugin: v1.4.1 → v1.4.2

## User feedback addressed

1. Lane background looked brown — too warm.
2. Horizontal scrollbar appeared mid-page, not at the bottom.
3. Toolbar bar was invisible (white on white) → dropdowns "disappeared"
   and didn't look like they were sitting inside a bar.
4. Dropdown triggers had no shadow / no visual weight.
5. Right-most lane was getting clipped without proper scroll handling
   (root cause of the scrollbar bug).

## Fixes

### Lane bg → cool neutral grey
- `--pck-bg-lane`: `#f5f5f4` (warm) → `#f4f4f5` (cool neutral, zinc-100
  family).

### Scrollbar moved to page bottom
- `kanban.module.css` `.root`: removed `overflow-x: auto;
  overflow-y: hidden;`. Was creating an inline scrollbar at the bottom
  of the grid's content height (mid-page when lanes were sparse).
- Added `width: max-content; min-width: 100%; min-height: 100%` so the
  grid grows to fit its content horizontally and fills the wrapper
  vertically.
- `SetsBoard.tsx`: wrapper className `overflow-x-auto` → `overflow-auto`
  so the outer flex container handles both axes; scrollbar now sits at
  the bottom of the available content area (page bottom).

### Toolbar reads as a visible BAR
- New token `--pck-bg-toolbar: #fbfbfc` — faintly off-white so the bar
  has subtle presence on a white page without being heavy.
- New token `--pck-shadow-toolbar: 0 1px 2px rgba(0,0,0,0.04)` — soft
  drop-shadow below the bar so it reads as a layered surface.
- `filters.module.css` `.toolbar`: bg → `--pck-bg-toolbar`,
  `box-shadow: var(--pck-shadow-toolbar)` added. Hairline bottom
  border kept for the seam.

### Dropdown triggers get shadow + stronger border
- New token `--pck-shadow-control: 0 1px 2px rgba(0,0,0,0.05)`.
- `--pck-control-border`: `rgba(0,0,0,0.08)` → `rgba(0,0,0,0.12)`
  (more visible on the off-white bar).
- `.trigger`: `box-shadow: var(--pck-shadow-control)` added at rest,
  upgraded to `--pck-shadow-card-hover` on hover.
- `--pck-card-border`: `0.06` → `0.08`; `--pck-lane-border`: `0.05` →
  `0.06` — small uniform bump so card edges and the toolbar seam read
  consistently against the new bar bg.
