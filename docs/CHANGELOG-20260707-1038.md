# Changelog — 2026-07-07 10:38 — Deliveries table v2: project editing, count cells, type colors, Assignee, column layout

## Summary
Five user requirements, shipped as two pairs (backend data, then frontend):
project rows edit the real project, Images/Copy/Videos show actual counts, Type
pills get predefined colors, a new Assignee column, and SEO-style column
reorder + resize.

## Pair 1 — backend [projects-counts-delivery-assignees] (039399a → 80475a7)
- `assets/controller.php get_projects`: the batch count query now also returns
  `imageCount`/`videoCount` (`SUM(CASE WHEN type='image'/'video')` — those are the two
  values assets store) + a second batch on `copy_results` → `copyCount`. Additive
  response fields; no schema change.
- `deliveries/controller.php list_items`: batch-attaches `assignees: [{id, name}]`
  per delivery (`delivery_assignments INNER JOIN pcm_users`, one query for the whole
  list). Read-only enrichment — assigning stays in the Users module
  (PUT /users/{id}/deliveries).
- Verified: php -l clean on both.

## Pair 2 — frontend [deliveries-table-v2] (754a08c → dd614ef)
- **DataTable `layoutKey` prop (opt-in)** — passing a localStorage key enables the
  SEO spreadsheet's column UX via the SHARED primitives (`useColumnLayout` +
  `ColumnHead`): drag a header to reorder, drag its right edge to resize, persisted
  per browser. Numeric column `width`s seed the defaults; a `<colgroup>` drives
  `table-fixed`; the chevron column stays fixed; the hook runs unconditionally
  (rules of hooks) but never persists without a key. Legacy header path untouched
  for consumers without a key (Sites unchanged).
- **Project name is inline-editable and renames the REAL project** — new
  `renameProject` on `useDeliveryProjects` → existing `PATCH /assets/projects/{id}`
  (`assets.renameProject`); rethrows on failure so the cell reverts its draft.
- **Images/Copy/Videos cells are clickable COUNTS** (tabular numerals, muted at 0,
  still jump into the project on that tab). The sub-header row labels the columns,
  so the cell is just the number.
- **Type pills: predefined palette** — 7 soft bg/ink pairs (lane-accent family); a
  type KEY hashes to a stable slot so a type keeps its color across sessions and
  label renames. No preset-schema change needed.
- **Assignee column** (after Modules) — assignee names from the new list
  enrichment, comma-joined + truncated with full list in the tooltip, sortable by
  first name, read-only ("—" when unassigned).
- Deliveries layout key: `pcm:deliveries:col-layout:v1`. Sub-rows/sub-header
  realigned to the 9-cell grid (8 data columns + chevron); sub-row mapping is
  positional by design — it keeps its own labeled order under whatever column
  order the user drags into place.
