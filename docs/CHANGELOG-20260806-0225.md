# CHANGELOG — 2026-08-06 02:25 — CARD INTEGRITY (owner GO)

One line per change, newest last. Companion: `docs/plans/2026-08-06-card-integrity.md`.

- T1 SAVE CANNOT DESTROY: `PCM_Approvals_Service::sanitize_document_html()` replaces the bare `wp_kses_post()` on document bodies (both the `articles` and `custom` buckets). kses drops any `src` whose scheme is missing from `wp_allowed_protocols()`, and that list has no `data:` — so every inline base64 image came back source-less, Tiptap dropped the node, and the next close saved the resulting EMPTY document over the real one. That is how approval set 26 lost 489,939 bytes on 2026-08-06. `data:` is now permitted for the duration of that one call via `kses_allowed_protocols` and removed again immediately; the full tag/attribute filter still runs. Second guard: `would_erase_document()` — an empty document is never stored over content, so no future hydration failure, dropped node or half-mounted view can erase work again. HARNESS: 95/95 (was 88), the 7 new cases extracted from the REAL service file, first case = the set 26 regression. Scope stated in the test itself: only the erase guard is provable standalone; the kses widening depends on WordPress's own protocol list and is proven in web context, not against a shim. VERIFIED: php -l, harness 95/95.
- T2 IMAGES LEAVE THE DOCUMENT: all three producers of inline base64 now upload to the media library and store a URL. `useImageUpload` (the hook the Writer canvas already uses) gains `uploadDataUrl()` for canvas output — annotations and draw layers arrive as finished PNGs, so they skip the File round-trip and the second lossy pass. Call sites: `CustomCardEditor.insertImageFiles()` (paste/drop, was `readAsDataURL`), `ImageAnnotator.onInsert` (was inserting `toDataURL` straight into the doc), and the draw layer. The draw layer emits after EVERY stroke, so its output is now buffered in `pendingOverlay` and uploaded ONCE on done/cancel/toggle-off — a drawing is one file, not one per stroke; `toggleDraw` and "Done" share `finishDraw()` so the two exits cannot disagree. Result: a card is kilobytes, not the 489,939 bytes measured on set 25. VERIFIED: tsc 59 = baseline, build OK.
- T3 ONE TYPE SCALE: the card editor reads `--pcm-doc-*` (16px/1.5). Recorded as an owner decision superseding 2026-08-05 — that day it was bound to `--pcm-prose-*` (11px) to match the Writer's A4 pad, and in the wide centred sheet the owner rejected it as unreadable. The WRITER pad keeps `--pcm-prose-*`: an admin work surface in a narrow panel is a different job. DELETED as dead: `.pcm-notion-prose` (27 rules) and `.pcm-notion-draw` / `.pcm-notion-prose-wrap` — the second read-only renderer's type scale, orphaned when the card collapsed to ONE editor with two modes. Zero TSX consumers, verified before removal. index.css shipped 366.28 -> 363.79 kB. VERIFIED: tsc 59 = baseline, build OK.
