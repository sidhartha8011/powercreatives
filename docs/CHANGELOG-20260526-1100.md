# CHANGELOG 2026-05-26 11:00 — Approvals bar → shadcn migration + empty-state split

Plugin: v1.4.6 (user-controlled version; this change is an architectural
refactor that would normally warrant a minor bump but version is owned by
the user — not bumped here).

Senior-dev refactor per UX brief. The Approvals pipeline bar now uses the
same shadcn primitives every other module uses (Projects, etc.) instead
of a parallel CSS-module renderer that was constantly losing the
specificity war against WP admin + Tailwind v4 layer base. Filter +
sort engine (pure logic) is untouched.

No dead code, no tech debt, no parallel CSS system.

## B. Empty state split

### KanbanBoard.tsx no longer hides itself on `items.length === 0`

The board now ALWAYS renders the lanes when `columns.length > 0`. Empty
items just means each column renders its own per-column `emptyHint`.
The board only short-circuits for `error` (renders DefaultErrorState) or
`isLoading` (renders DefaultLoadingState). Removed the `items.length ===
0` branch and the unused `emptyState` slot prop.

### SetsBoard owns the two distinct empty states

- `isDataEmpty` = `!isLoading && sets.length === 0` → render the
  onboarding `DefaultEmptyState` ("No shared Ad Sets in pipeline"), hide
  the board entirely.
- `isFilterEmpty` = `!isLoading && sets.length > 0 && filteredItems.length === 0`
  → render a thin notice "No sets match your filters." + a "Clear filters"
  link, AND keep the board rendered with empty lanes so the user does
  not lose her mental model of the pipeline.

### Per-lane empty hints

Added `emptyHint` to every entry in `setColumns.ts`:
- Draft → "No drafts"
- Internal → "Nothing awaiting internal review"
- Client → "Nothing awaiting client review"
- Create → "No campaigns to build"
- Launch → "No campaigns ready to launch"
- Live → "No live campaigns"
- Archived → "Nothing archived"

The existing `.columnEmpty` style in `kanban.module.css` renders these
as faint italic text in the lane body; combined with the lane's
`min-height: 120px`, empty lanes hold their visual position consistently.
