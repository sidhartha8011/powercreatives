# CHANGELOG — 2026-07-09 07:00 — [section-modal-phase2]

**Section editor, phase 2 of 2 (the EDITOR UI).** Rides entirely on phase 1's
engine (37dc89a, connector 2.8.0) — frontend only, connector untouched.

## What ships

**`SEO/SectionModal.tsx` (new) — the floating section editor:**
- Draggable (grab the header), NON-blocking floating panel — custom portal,
  no overlay, the SEO table behind stays fully interactive. Esc steps back
  (suggestion → edit → close); X closes. No new dependency.
- **Read view:** the whole section (heading + paragraphs) as readable
  FORMATTED text (bold/links/lists rendered — served state when a section
  rule is active; otherwise the original with active paragraph rules folded
  in). A `</>` toggle shows the raw HTML (replaces the old P-chip popup).
- **Edit view:** TipTap editor (headings H1–H4, paragraphs, bullet/numbered
  lists, bold/italic/underline/strike, links) with a SELECTION bubble toolbar
  (Airtable pattern) — merge, split, delete, add paragraphs freely. Accept /
  Cancel under the text.
- **AI (staged):** header **Re-write** rewrites the whole section via
  `section-optimize` → rendered suggestion with Accept / Reject / Re-generate
  (accepting lands in the editor for final tweaks — nothing saves until the
  green Accept).
- **Save:** ONE `section` rule (UPSERT; editing back to the original deletes
  it server-side — clean revert; push-fail rolls back, from phase 1).
- **New sections:** create mode with placement (before/after any existing
  heading, default after the last), an optional AI topic ("FAQ about
  pricing") → Generate, or write manually. Existing added sections re-open
  for editing and have **Remove** (clean removal via empty replacement).

**HeadingsPanel wiring:**
- **P chip** on a paragraph row now opens its SECTION in the editor (orphan
  paragraphs without a heading keep the old HTML popup). Paragraph text click
  keeps the inline quick-edit — rows stay the fast path.
- Heading rows gain a row-hover **expand icon** (opens the section) and a
  **primary dot** when a section rule serves that section.
- Paragraph rows INSIDE a section-served section route their click into the
  section editor (honest: a row-level paragraph rule would miss — the block
  was already swapped) — with the explaining tooltip.
- **Added sections render as rows** at their served spot (NEW chip + title
  parsed from the replacement; 'before' rows ahead of their anchor, 'after'
  rows at the section end) — click to edit/remove.
- **“+ Add section”** row at the end of the outline (remote, ≥1 heading).
- **LOCAL tab:** the modal opens as a read-only formatted view (routing law —
  no engine on the hub's own site; honest tooltip). An upgrade over the raw
  HTML popup for local too.
