# Non-blocking document saves and checklist alignment — 2026-08-06 07:53

- Approval documents now dismiss immediately while the mounted editor completes pending media work and the final document save in the background; a failed background save restores the retained document instead of discarding it.
- The document's portal shell keeps one editor instance across visible and background-saving states; state changes no longer remount Tiptap and discard pending media patches.
- Older save acknowledgements no longer replace the document ref while a newer local revision is dirty. The approval query is refreshed once the editor's complete save queue drains, rather than after intermediate autosaves, preventing rapid consecutive edits from being based on stale server content.
- Shared Tiptap task lists now use a controlled 16px Notion-style checkbox with fixed first-line alignment, hover, focus, checked, and completed-item states.
