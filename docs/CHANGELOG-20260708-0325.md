# CHANGELOG 2026-07-08 03:25 — Video: Consolidated sidebar & implemented parallel video generation

Consolidated the Video module's sidebar using shared components (`GlobalEngineSelector` and `GlobalProductionParameters`) and refactored the generation loop to run all tasks in parallel.

## UI Changes / UX Refinements

- **Consolidated Model Selection Dropdown:**
  - Replaced the large cost-tier accordions and checkbox list with the shared `<GlobalEngineSelector type="video" selectedIds={selectedModels} onChange={setSelectedModels} multiSelect={true} />`.
  - Dramatically reduced the vertical space taken by model selection in the sidebar.
- **Consolidated Production Parameters Sliders:**
  - Replaced custom sliders for Angles and Variations with `<GlobalProductionParameters angles={numVersions} onAnglesChange={setNumVersions} variations={variationsPerModel} onVariationsChange={setVariationsPerModel} maxAngles={6} maxVariations={3} />`.
  - Moved **Duration** and **Format** controls to their own dedicated section ("Format & Duration") for better layout spacing and visibility.
- **Code Cleanup:**
  - Removed unused local states (`expandedTiers`) and helpers (`toggleTier`, `toggleModel`) from `Video/index.tsx`.

## Performance / Core Generation Changes

- **Parallel Generation Loop:**
  - Refactored `handleGenerate()` in `Video/index.tsx` from a blocking sequential loop to concurrent execution.
  - Flattend the nested loops into a list of tasks.
  - Generates placeholders for all videos simultaneously on launch.
  - Runs all generation promises (blocking REST calls or Kie.ai async status polling loops) in parallel using `Promise.allSettled()`.
  - Dynamically updates individual placeholders and global progress status as each video finishes or fails.
