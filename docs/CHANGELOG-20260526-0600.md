# CHANGELOG 2026-05-26 06:00 — Kanban Minimal Visual Refactor

Pure UX/visual refactor of the Approvals kanban. No logic, no API, no data
shape changes. Lane registry, filter registry, sort registry, DnD, status
mutation, URL-sync, dialogs — all untouched.

Plugin: v1.4.0 → v1.4.1
DB: v1.9.0 (unchanged)

## Visual changes

### Surfaces
- Approvals page background: warm-grey `#f8f8f7` → white `#ffffff`.
- Lane fill: white-with-border → soft grey tray `#f5f5f4`, no border, radius
  10px, fixed width 240px.
- Card: white with hairline border `rgba(0,0,0,0.06)`, radius 6px, single-row
  layout, min-height 32px, padding 6px×10px.
- Shadow rest state removed on cards; subtle shadow only on hover.

### Toolbar
- Collapsed to a single row spanning the board (height 40px, hairline bottom
  border). Filters left, sort right. No full enclosure.
- Dropdown trigger restyled compact (height 28px, hairline border, 12px
  font) so the three existing multiselects (Brand / Project / Approval set)
  read as proper input affordances instead of ghost buttons.

### Pills
- Inline-flex (hugs the label) instead of full-width header bar.
- 11px font, 2px×8px padding, 18px tall.
- Dot indicator removed from header rendering. (`column.dotColor` field
  retained in `setColumns.ts` registry; just no longer drawn.)

### Cards
- Meta row removed (was: project · approval count · feedback count).
  Title is now the only visible content. Action chips (Copy link, View
  feedback) remain as hover-only absolute overlay so card height is fixed.
- `summarize()` helper simplified to only compute `feedbackCount` (the
  one field still consumed, used to gate the "View feedback" chip).
