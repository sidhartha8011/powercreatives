## 🚀 Features

### 🔴 Essential

- [ ] **⚠️ CRITICAL: Thinking Model Support (Gemini 2.5 Pro)** — `max_completion_tokens: 2048` i `service.php:171` (audience generation) är **för lågt** för thinking-modeller. Gemini 2.5 Pro använder dolda resonemangstokens som konsumerar samma `max_completion_tokens`-budget. Resultat: modellen "tänker" i ~2045 tokens → 0 tokens kvar → **tomt svar**. Flash fungerar för den har inga thinking-tokens. **Fix:** Öka `max_completion_tokens` till minst 8192–16384 för thinking-modeller, eller detektera thinking-modell och sätt högt automatiskt. **Påverkar:** Alla moduler som anropar `PCM_LLM::invoke()` med lågt `max_tokens` — Copy (audience gen, copy gen), Image (concept gen), Video (angle gen, enhance). **Root cause:** `diag-2026-03-02.jsonl` — `completion_tokens: 0, total_tokens: 2304, prompt_tokens: 259`.

- [ ] **Writer: `imageStyle` ignoreras av Kie.ai** — UI-dropdown finns (Auto/Realistic/etc.), värde skickas till backend, men **Kie.ai-providern (`class-pcm-provider-kieai.php`) saknar style-parameter mappning**. Bara OpenAI-providern stödjer `$body['style']`. Flux-modeller via Kie.ai genererar alltid i default-stil oavsett val. **Fix:** Antingen implementera style→prompt injection (bästa approach för Flux), eller ta bort style-dropdown när Kie.ai är aktiv provider. **Fil:** `includes/core/providers/class-pcm-provider-kieai.php`

- [ ] **Writer: Per-bild model-val saknas** — Alla bilder i en artikel använder SAMMA modell (från `generationSettings.imageModel`). LLM-schemat har inget `requested_model` fält per mediaManifest-item. **Fix (låg prio):** Utöka `article_schema()` med `requested_model` per manifest-item, eller lämna som globalt val (nuvarande beteende är acceptabelt).
