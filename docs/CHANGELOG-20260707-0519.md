# Changelog — 2026-07-07 05:19 — Shared EntityCard primitive + delivery card UX v2

## Summary
New domain-agnostic `EntityCard` primitive (Notion-style detail card, same philosophy as
the shared Kanban primitive) and the delivery card rebuilt through it with the full UX
spec: silent auto-saves, text-at-rest cells, whisper headers, composer log.

## New shared primitive — `app/src/components/shared/EntityCard/`
- `EntityCard` — white 5xl Dialog shell, ONE scroll context, 32px padding, no footer,
  sr-only title/description for a11y.
- `EntityCardTitle` — inline-editable title: hover affordance, Enter commits, empty
  restores, transient "Saved ✓" whisper (aria-live).
- `PropertyTable` — declarative `PropertyDef[]` (text / select / multiToggle): borderless
  text-at-rest cells with hover/focus reveal, fixed column widths, muted empty labels,
  optional status dots on select options, chips (not sentences) for multiToggle.
- `EntityCardSection` — 11px uppercase whisper header + right action slot; enforced
  24px/8px spacing scale.
- Knows nothing about any domain. Reference consumer: Deliveries.

## Deliveries
- `DeliveryDialog.tsx` re-expressed through the primitive: 6 PropertyDefs (Status with
  Kanban-colored dots | Client | Type → applies module preset | Module access chips +
  checkbox popover | Brand | External ID).
- Auto-save is silent: optimistic apply → "Saved ✓" whisper on ack → REVERT on failure
  (errors toast). `useDeliveries.updateDelivery` success toast removed (error toast kept).
- Edit mode has no footer (Esc/✕ close); create mode keeps one primary Create button.
- Projects section: ✕ revealed on row hover, borderless site select, quiet "N media"
  text, empty state = dashed ghost add-button opening the same AddProjectMenu.
- Log section: composer with in-field send button (Enter submits), entries show
  author · relative time (full timestamp on hover), max 10 + "Show all (N)".
