# Changelog — 2026-05-14

## Auto-logo + BrandSummaryCard + Parallel Generation (A+B+C)

- **Added:** Auto-populate logo from brand assets when brand is selected (`Image/index.tsx` useEffect)
- **Added:** `BrandSummaryCard` component in ContextPanel — shows business summary, niche, location, colors, logo when brand selected

- **Changed:** `pipelineExtra` and `resolvedProvider` hoisted out of inner loop (computed once, reused)
