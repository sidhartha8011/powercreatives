# Implementation Plan: GPT Image 2 Integration

**Date:** 2026-05-12
**Author:** Senior Developer

## 1. Faktabas (Facts Based Ground)
*   **API-dokumentation (Kie.ai):** Dokumentationen för Kie.ai visar att den nya GPT Image 2-funktionaliteten nyttjar deras generiska "Marketplace API" (`/api/v1/jobs/createTask`). De officiella modellnamnen är:
    *   `gpt-image-2-text-to-image`
    *   `gpt-image-2-image-to-image`
*   **Nuvarande arkitektur i PowerCreatives:**
    *   Alla marketplace-modeller läses in dynamiskt från konfigurationsfilen `app/shared/kieMarketplaceModels.json`.
    *   Klassen `class-pcm-kie-api.php` avgör hur anropen görs – om modell-ID:t hittas i JSON-filen ruttas anropet automatiskt till `PCM_Kie_Marketplace::create_task`.
    *   Just nu finns bara "GPT Image 1.5" registrerad i JSON-filen (`kie-gpt-image-1.5-t2i` och `kie-gpt-image-1.5-i2i`).
*   **UI-Rendering:** Vårt React frontend bygger upp sina val baserat på denna JSON. Inga hårdkodade dropdowns finns, vilket följer `@architecture.md` "NO STATIC MENUS" / "NO THINKING IN UI".

## 2. GAP (Vad saknas?)
Eftersom `gpt-image-2-text-to-image` helt saknas i vår JSON, skapas inte menyvalet i gränssnittet och applikationen har därmed ingen brygga till det nya API:et.

## 3. Senior Developer Lösning (Plan)
**Mål:** Integrera GPT Image 2 utan att skriva om någon logik (100% config-driven).

1.  **Ingen kod behöver skrivas i Backend-klasserna:**
    *   `class-pcm-kie-api.php` och `class-pcm-kie-marketplace.php` fungerar redan som de ska, då de dynamiskt hanterar allt som finns i JSON-registret.
2.  **Uppdatera Registry (kieMarketplaceModels.json):**
    *   Lägg in ett nytt JSON-objekt för `kie-gpt-image-2-t2i` (Text-to-Image).
    *   Lägg in ett nytt JSON-objekt för `kie-gpt-image-2-i2i` (Image-to-Image).
    *   Sätt `vendor` till "OpenAI" och `displayName` till "GPT Image 2".
    *   Återanvänd befintliga parametrar för bildstorlek/aspect ratio som GPT 1.5 använde för att matcha det `PCM_Kie_Input_Mapper` förväntar sig.
3.  **Bibehåll bakåtkompatibilitet:**
    *   Låt GPT Image 1.5 ligga kvar i filen tills Product Owner explict säger att den ska bort (minimerar risk för regression).
4.  **Test och Verifiering:**
    *   När konfigurationsfilen är uppdaterad testas hela flödet i appen (tack vare den tillagda API-nyckeln) för att säkerställa att Kie.ai accepterar payloaden för GPT Image 2.

*Denna plan är designad utifrån 100% config-driven arkitektur och medför noll teknisk skuld.*
