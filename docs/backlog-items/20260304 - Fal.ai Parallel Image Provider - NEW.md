# Fal.ai — Parallel Image Generation Provider

> **Status:** NEW
> **Priority:** High (reliability/redundancy)
> **Estimated effort:** 1–2 dagar
> **Routine:** `docs/routines/adding-provider.md`

## Varför

Kie.ai är idag vår enda image generation provider (utöver Google Imagen direkt). Vid driftstörningar (som 525-felet 2026-03-04) har vi ingen fallback. Fal.ai ger redundans + potentiellt lägre priser.

## Vad

Integrera Fal.ai som parallell image generation provider — alla modeller dynamiskt registrerade, samma UI, samma routing.

## Fal.ai API-mönster

```
POST https://queue.fal.run/{model_id}
Headers: Authorization: Key {api_key}
Body: { prompt: "...", image_size: "landscape_16_9", ... }
→ Returns: { request_id: "abc123" }

GET https://queue.fal.run/{model_id}/requests/{request_id}/status
→ Returns: { status: "COMPLETED", response_url: "..." }

GET https://queue.fal.run/{model_id}/requests/{request_id}
→ Returns: { images: [{ url: "https://..." }] }
```

Matchar exakt vårt befintliga Kie.ai-mönster (submit → poll → result).
