## [1.3.0] — 2026-04-19

### Writer Module — Image Orchestration Pipeline (Complete Fix)
- **Fix:** Removed `on_chunk` SSE injection in `service.php` — blocking mode required for `invoke_json()` JSON parsing.
- **Fix:** Resolved `'auto'` model sentinel to first available image model from active integrations instead of hardcoded `'openai'`.
- **Fix:** Added `imageModels` to `useEffect` dependency array — prevents skeleton images from getting stuck.
- **Fix:** Extended Tiptap Image node with `data-media-id` as proper schema attribute — enables skeleton→image replacement during HTML parsing round-trip.
- **Fix:** Sequential image processing — prevents ProseMirror position invalidation from parallel dispatches.
- **Fix:** SEO alt-text from LLM `mediaManifest` now applied during skeleton replacement.
- **Refactor:** Document-scoped image state via namespaced keys (`docId::mediaId`) — eliminates cross-document contamination without fragile reset logic.
- **Nytt:** CSS states for image lifecycle: `.pcm-skeleton` (pulse animation), `.pcm-generated-image` (fade-in reveal), `.pcm-image-error` (error border).
- **Build:** PASS (`✓ built in 18.01s`)
- **E2E:** Verified with "coffee brewing" (2 images) and "pizza recipe" (1 image).

### Berörda filer

- `app/src/modules/Writer/hooks/useImageOrchestration.ts` — Complete senior refactor

## [1.2.0] — 2026-04-17

### Writer Module — Zero Hardcoding (Phase 2)
- **Refactor:** Migrerade inställnings- och instruktionsprompter för the Writer module i `service.php` från hårdkodade strängar till databas-drivna mallar.
- **Nytt:** Lade till `get_system_prompt()` och `get_default_prompts()` så att Writer-prompter nu kan redigeras globalt från Plugin Settings.
- **Förbättring:** Eliminerat the injection-risker genom att använda `resolve_prompt_placeholders()` istället för klient-drivna master prompts.

### Writer Module — SSE Push Pipeline (Phase 3)
- **Refactor:** `controller.php::generate_article()` migrerad från blocking REST (`return $this->success()`) till event-driven SSE via `PCM_SSE::start(600)`.
- **Förbättring:** `service.php` hookar nu `on_chunk => PCM_SSE::llm_callback()` för live heartbeat-tokens som förhindrar 504 Gateway Timeouts.

### Writer Module — Frontend SSE Consumer (Phase 4)
- **Nytt:** `app/src/lib/sse.ts` — Shared SSE stream parser utility (extraherad från Copy-modulens inline-logik).
- **Refactor:** `ReviewEditorCanvas.tsx` — Ersatte `trpc.writer.generate.useMutation()` med authenticated `fetch()` + `parseSSEStream()` för korrekt SSE-konsumtion.
- **Fix:** Stale `generateMutation.isPending` reference → `isGenerating` state.
- **Build:** PASS (`✓ built in 19.22s`).
