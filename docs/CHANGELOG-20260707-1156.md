# Changelog — 2026-07-07 11:56 — Delivery Lead + table polish (items 2–6)

## Pair 1 — [delivery-lead] (dec9928 → 23cffef, DB 1.35.0 → 1.36.0)
- **The lead IS an assignment.** `delivery_assignments` gains `role varchar(20)
  DEFAULT 'member'` (additive dbDelta). A lead = an assignment row with
  role='lead' — so PCM_Access, module grants (deliveries.modules), and
  notification visibility all apply untouched; zero parallel access code.
- **`PATCH /deliveries/{id}/lead {userId|null}`** (manage_options, owner-checked
  like update_item): demotes any current lead to member (access is never
  silently revoked — removal stays explicit in the Users module), promotes an
  existing assignee in place, or inserts a new assignment — the insert runs the
  same invalidation tail the Users module uses (PCM_DB::invalidate deliveries +
  brands for the new assignee, PCM_Access::reset_memo). Returns fresh assignees.
- List enrichment now carries `role`; Users-module writes default to 'member'
  via the column default (its code untouched).
- **Frontend:** Assignee column → **Lead** — editable select of all platform
  users (users.list; the select component mounts only for admins since that
  route is admin-only; non-admins see the read-only name). Non-lead members
  show in the tooltip ("Team: …"). trpc `deliveries.setLead`.

## Pair 2 — [deliveries-table-polish] (292d4c2 → d8af260) — items 3–6
- **(3) Non-admin gating** — every delivery cell renders a read-only version
  for non-admins (name text, status/type pills, brand text, module chips, ID
  text, lead name) instead of editors whose saves the server would refuse.
  Project SUB-ROWS stay editable: those mutations are ownership-scoped
  (edit_posts), not admin-only — the server remains the authority.
- **(4) Row delete** — quiet trash icon in the name cell (admin-only) → the
  board's existing delete-confirm AlertDialog (same flow as the Kanban card).
- **(5) Per-column header filters** — the EXISTING shared feature (SEO's
  ColumnHead filter dot + useColumnFilters) wired via a new optional
  `filterDefs` prop on DataTable (rows filter before sorting; requires
  layoutKey). Deliveries defs: name/lead/ID text-contains; status/type/brand
  option lists. This REPLACES the proposed brand/delivery/project searchable
  dropdowns — no new feature was built.
- **(6) Reset columns** — RotateCcw button in the bar (table view): clears
  `pcm:deliveries:col-layout:v1` and remounts the table so useColumnLayout
  reloads defaults.
