# CHANGELOG 2026-05-27 13:05 — Client Review Board: UX Background, Layout & Tooltip Refinements

Three targeted UX refinements to the Client Review Board to enhance visual warmth, layout balance, and copy card cleanliness.

## Changes

### 1. Warm Cream Background + Harmonized Glows
- Changed page background from clinical white (`#ffffff`) to warm cream (`#faf8f5`)
- Replaced cold blue glow blobs with warm amber/sand/honey tones that harmonize with the `--ink` palette:
  - Glow 1: `#5e8df0` → `#d4a574` (amber), opacity 0.75 → 0.45

  - Glow 3: `#9bb9ff` → `#e8d5b8` (honey), opacity 0.6 → 0.4

### 2. Hero Status Layout Rebalance
- Moved "X of Y approved" progress bar + "Awaiting your review" status pill from sticky toolbar to hero section
- Removed "Draft saved" indicator from toolbar
- Sticky toolbar now contains only: filter tabs | deadline | approve button

### 3. Copy Card Info Tooltip
- Replaced visible uppercase audience/angle metadata text (`.pcm-copy-platform`) with a small ℹ️ icon (`.pcm-copy-info-trigger`) positioned in the top-right corner of copy cards
- On hover, a CSS-only tooltip (`::after` pseudo-element) reveals the audience + angle text
- Zero new component imports — pure CSS tooltip with smooth opacity + transform animation
