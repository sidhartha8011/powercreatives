# CHANGELOG - 2026-05-23

## [1.2.2] - 2026-05-23

### Fixed
- Fixed TypeScript typecheck errors in the Ads Module `index.tsx` by explicitly typing the `imageVariations` and `numVersions` states as `<number>` to override strict literal type inference caused by configuration constants.
- Cleaned up unused imports (`useImageModelsForGeneration`, `TIER_CONFIG`, `trpc`, and `CostTier`) from `index.tsx`.
- Exposed and implemented the `cancel` callback in `useAdsOrchestration.ts` using `useCallback` to abort the active SSE/fetch stream via `abortRef`, reset phase to `'idle'`, set progress to `null`, and display a success/info toast.
- Cleaned up the unused `textCount` parameter in the `runImagePhase` function signature and invocation in `useAdsOrchestration.ts`.
- Integrated the `onCancel` prop in `AdsSidebar.tsx` and updated the bottom Generate button to function as an interactive "Cancel Generation" button (with destructive styling) when `isGenerating` is active, keeping the button clickable and enabled.

### Added — SVG-to-PNG Brand Asset Conversion (DB v1.7.0)
- Added `PCM_Image_Utils::rasterize_svg_to_png()` — converts SVG vector files to high-quality PNG using Imagick (300 DPI, transparent background, max 1024px). AI image generation models (Flux, DALL-E, etc.) cannot process SVG files as reference input.
- Added `PCM_Image_Utils::is_svg()` — helper to detect SVG MIME types and file extensions.
- Hooked SVG→PNG conversion into `PCM_Brands_Service::upload_asset()` and `PCM_Brands_Service::add_asset_from_url()` — all SVG logos are automatically rasterized at storage time. No module-level changes needed.
- Added `PCM_Schema::migrate_brand_svg_to_png()` — one-time v1.7.0 migration that converts existing SVG brand assets in the database to PNG (affects brand 9 / Bright Tandhälsa).
- Bumped `PCM_DB_VERSION` from 1.6.0 to 1.7.0 to trigger the migration on next page load.
- Removed temporary debug console.log from `useAdsOrchestration.ts`.

### Fixed — Missing `role` Parameter in Reference Image Saving
- Added `role: 'reference'` to `useBrandFetch.ts` — "Fetch Brand" (edit mode) now correctly saves scraped images as reference assets instead of silently failing with 400 "Asset role is required."
- Added `role: 'reference'` to `ReferenceImageSelector.tsx` (Fetch from URL) — direct image URL downloads now save correctly.
- Added `role: 'reference'` to `ReferenceImageSelector.tsx` (Upload) — file uploads now save correctly.
