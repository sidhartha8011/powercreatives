# CHANGELOG 2026-05-26 10:33 — Client Review Board: Dynamic Comment Status & Seen/Unseen Tracking

Implemented a fully dynamic comments thread status state-machine and dynamic unread (seen/unseen) tracking overlays that automatically highlight new feedback and replies while visually cleaning up comment reply cards.

Plugin: v1.4.8

## UX Refinement & Enhancements

- **Replies Visual Cleanup:**
  - Removed all status badges and dropdowns from nested replies (`parentId !== null`), keeping the dropdown strictly on root-level comment cards to govern the whole thread.

- **Dynamic State Machine Auto-Transitions:**
  - Configured top-level comments to automatically transition status based on participant roles:
    - If a **Client** adds a new comment or replies to an existing thread, the root status auto-transitions to `'New'`.
    - If a **Team member** replies to an existing thread, the root status auto-transitions to `'Team reply'`.
    - Manual overrides to `'Done'` remain closed until a client replies again.

- **Dynamic Seen/Unseen Highlight System:**
  - Extended the `CommentEntry` data interface with `readBy?: ('client' | 'team')[]` metadata.
  - Highlighted unseen comments from the other role with an elegant glowing blue dot (`.pcm-comment-unread-dot`) and a visual border overlay (`border-left: 3px solid #2563eb`).
  - Added an automatic mark-as-read effect hook inside `ClientCommentInspector.tsx` that marks comments as read by the current viewer after 1.5 seconds of viewing, syncing cleanly with the WordPress database.
  - Refined the asset card notifications to only flash the blue unread dot on cards when actual unseen comments exist for that viewer role.
